How I work

Four principles that show up in every program above.

Start with the moment, not the roadmap

Find where a problem actually shows up for the person living it before scoping a solution around it.

Governance should be the fastest path

The frameworks that stick are the ones built with the people who'll use them, not handed down to them.

Data should settle arguments, not start them

Pull the number before the opinion - it changes which conversations are even worth having.

Escalate by exception

Blockers get surfaced the day they appear, not saved for the next status meeting.
